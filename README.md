## Start here

- Use the tools on **agmad.net**: images, text, colors, developer tasks and password generation. No account required for the current public tools.

- Follow development through verified changes and evidence; plans are not releases.

## Repository organization

This public hub contains studio documentation and project references. Product implementations retain their own repositories and release boundaries.

- `docs/tools/`: tool catalog and availability.
- `docs/editorial/`: development-note, article and video workflow.
- `docs/projects/`: project briefs and testing boundaries.
- `journal/`: unpublished templates and development notes.
- `video/outlines/`: video outline templates.
- `.github/ISSUE_TEMPLATE/`: safe bug/documentation reports.

No automatic website publishing or executable auto-update pipeline is configured here. Template files are clearly marked; they are not published articles or activity records.

## Privacy and licensing

Current public tool engines process inputs in the browser; site assets must load first. See individual tools for actual limits and privacy details. Never submit private passwords, customer data, proprietary JSON or copyrighted game data in issues.

Existing project licenses remain authoritative. This umbrella README does not apply the Tools code license to all projects, artwork or existing repository contents. Third-party attribution and brand redistribution review remain open for the prepared Tools packages.
