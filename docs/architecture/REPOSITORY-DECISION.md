# Repository boundaries

This repository is the public AGMAD studio hub: introduction, project references, tool catalog and editorial workflow. Existing product code, scanner/database infrastructure and technical milestone records remain in their own projects. This repository does not supersede their specifications or publish their private implementation.

The modular Tools source release is being prepared separately. Its current public usage destination is https://agmad.net/tools/. Source links and downloadable releases will be added only after publication review. There is no automatic updater or subscriber gate in this documentation hub.

AGMAD.net remains the canonical place to use tools and read polished articles. GitHub holds source references, issues, documentation and release notes. Development notes can summarize articles and link back; full articles are not duplicated or published automatically.
