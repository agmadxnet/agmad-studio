## Release boundaries

Installable source packages are not distributed here. Any future package must retain applicable licenses and attribution and document installation, dependencies, compatibility limits and rollback. Existing isolated installation checks do not establish end-user Windows or universal browser compatibility. Report a tool problem using synthetic input and your browser/version; never include passwords, customer data or proprietary content.
