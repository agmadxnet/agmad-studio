## Release boundaries

Before publishing installable source packages: finish third-party attribution and brand redistribution review, reconcile the live Core with the prepared source bundle, validate the release bundle, and document installation, dependencies and rollback. Existing isolated installation checks do not establish end-user Windows or universal browser compatibility. Report a tool problem using synthetic input and your browser/version; never include passwords, customer data or proprietary content.
