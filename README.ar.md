# أجمد — نصنع ما يستحق أن يكون.

استوديو مستقل للتكنولوجيا الإبداعية. نجرّب ونبني ونشارك ما نتعلّمه.

[الموقع](https://agmad.net/?lang=ar) · [الأدوات](https://agmad.net/tools/?lang=ar) · [اليوميات](https://agmad.net/journal/?lang=ar) · [الاشتراك](https://agmad.net/subscribe/?lang=ar)

الأدوات العامة الحالية متاحة داخل المتصفح دون حساب. Silent Cutter وAGMAD MENA قيد التطوير؛ لا نعرض الخطط على أنها منتجات مكتملة. أدوات المشتركين اتجاه مستقبلي وليست ميزة مطلقة حاليًا.

يُستخدم GitHub للمصدر والتوثيق والمشكلات والتطوير، ويظل الموقع وجهة استخدام الأدوات وقراءة المقالات. لا ننشر بيانات ألعاب أصلية أو بيانات خاصة ضمن أمثلة المشكلات.
